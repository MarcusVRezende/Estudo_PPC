
# title: Estudo_programacao_para_competicao

Repositório para armazenas minhas atividades e estudo sobre programação para competição

## Comando para rodar um arquivo .cpp

Compilar o arquivo

  ```bash
  g++ -g nome_do_arquivo.cpp -o nome_do_rograma
  ```

Rodar o executável

  ```bash
  ./programa
  ```

Rodar teste no arquivo

 ```bash
 /programa < in.txt
 ```
